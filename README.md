# Grafida — AI βοηθός για Έλληνες δικηγόρους (MVP slice)

**Το AI βοηθά — ο δικηγόρος αποφασίζει.** Κάθε παραγόμενο έγγραφο απαιτεί έλεγχο,
επεξεργασία και έγκριση από δικηγόρο πριν από οποιαδήποτε χρήση. Η εφαρμογή δεν
παρέχει νομικές συμβουλές· οι προθεσμίες που εμφανίζονται είναι υπενθυμίσεις
ημερομηνιών που καταχώρισε και επιβεβαίωσε ο δικηγόρος.

## Τι κάνει το slice

Σύνδεση → πελάτης → υπόθεση → μεταφόρτωση δειγμάτων ύφους → γεγονότα/σχετικά →
έλεγχος εξαγωγής AI → προσχέδιο στο ύφος σας → λίστα ελέγχου → έγκριση με
βεβαίωση → εξαγωγή σε Word → αναζήτηση (λέξεις-κλειδιά + σημασιολογική).

## Προαπαιτούμενα

- Docker Desktop
- [Ollama](https://ollama.com) εγκατεστημένο **στον host** (ώστε να χρησιμοποιεί GPU):
  ```
  ollama pull qwen2.5:7b
  ollama pull bge-m3
  ```
  Προαιρετικά δοκιμάστε ελληνικό μοντέλο (π.χ. Llama-Krikri-8B αν διατίθεται στο
  Ollama registry) και ορίστε `AI_CHAT_MODEL` στο `.env`.

## Εκτέλεση

```
cp .env.example .env      # και αλλάξτε το JWT_SECRET
docker compose up --build
```

- Εφαρμογή: http://localhost:3000 — σύνδεση με `SEED_EMAIL` / `SEED_PASSWORD` από το `.env`.
- API docs: http://localhost:8000/docs
- Χωρίς Ollama; Θέστε `AI_PROVIDER=mock` στο `.env` για demo με πλασματικές απαντήσεις.

## Tests

```
docker compose run --rm backend pytest -q
cd frontend && npm run build
```

## Χειροκίνητο σενάριο E2E

1. Σύνδεση στο http://localhost:3000/login.
2. «Πελάτες» → προσθήκη πελάτη.
3. «Υποθέσεις» → νέα υπόθεση για τον πελάτη.
4. «Το ύφος μου» → επιλογή τύπου «Ανακοπή κατά διαταγής πληρωμής» →
   μεταφόρτωση ≥3 (ιδανικά 10) παλαιών εγγράφων σας (.docx/.pdf/.txt) →
   «Δημιουργία προφίλ» → επιθεώρηση δομής/φρασεολογίας, διαγραφή φράσεων.
5. Στην υπόθεση: πληκτρολόγηση γεγονότων + μεταφόρτωση σχετικών →
   «Εξαγωγή στοιχείων με AI» → επιβεβαίωση κάθε στοιχείου (πεδία με πηγή
   και βεβαιότητα).
6. Προσθήκη προθεσμίας (χειροκίνητα — εσείς την επιβεβαιώνετε).
7. «Νέο έγγραφο με AI» → αναμονή σύνταξης (τοπικό μοντέλο: λεπτά σε CPU).
8. Στο προσχέδιο: επεξεργασία κειμένου, επίλυση/παράκαμψη (με αιτιολόγηση)
   των κόκκινων σημείων, τσεκάρισμα βεβαίωσης → «Έγκριση».
9. «Εξαγωγή σε Word» — κατεβαίνει .docx (μπλοκάρεται πριν την έγκριση).
10. «Αναζήτηση» → αναζητήστε λέξη από τα σχετικά σας.

## Λίστα ποιοτικού ελέγχου πραγματικού μοντέλου (χειροκίνητη)

- Το προσχέδιο χρησιμοποιεί εκφράσεις από το προφίλ σας;
- Όλα τα πραγματικά περιστατικά προέρχονται από τον φάκελο (όχι από τα δείγματα);
- Οι νομικές αναφορές φέρουν σήμανση [ΠΡΟΣ ΕΠΑΛΗΘΕΥΣΗ];
- Ποσά/ημερομηνίες/ονόματα συμφωνούν με τα επιβεβαιωμένα στοιχεία;
- Τα «σχετικό N» αντιστοιχούν σε πραγματικά σχετικά;

## Αρχιτεκτονική

AI APIs) · Έγγραφα/σχεδιασμός: `docs/superpowers/specs/`, πλάνο:
`docs/superpowers/plans/`.
